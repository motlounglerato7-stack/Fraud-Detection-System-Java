# Fraud Detection System Java

## Description
This is a beginner-friendly Java cybersecurity project that simulates how a financial institution may detect suspicious or fraudulent transactions using rule-based logic.

The system checks a transaction amount and location, then classifies the transaction as Normal, Suspicious, or Fraudulent.

## Cybersecurity Relevance
Fraud detection is an important part of cybersecurity in banking and financial systems. This project demonstrates basic risk-based thinking by identifying unusual transaction behaviour.

## Technologies Used
- Java
- GitHub

## Features
- Accepts transaction amount from the user
- Accepts transaction location from the user
- Compares the transaction location with the usual location
- Flags transactions as:
  - Normal
  - Suspicious
  - Fraudulent

Compile the program:
